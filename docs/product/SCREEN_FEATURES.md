# Trip Plan 화면별 기능 안내

문서 버전: 2.6
기준일: 2026-11-25
상태: 여행 계획 작성·여행 보기, 지난 여행 읽기 전용, 후보 장소와 숙소 포함

## 1. 문서 목적

이 문서는 현재 앱에 구현된 화면별 기능과 화면 이동, 입력 규칙, 오류 처리를 설명한다. 사용자 관점의 동작을 기준으로 하며 개발 시 화면 동작을 확인하는 기준 문서로도 사용한다.

## 2. 전체 화면 구성

| 화면 | 주요 목적 | 진입 경로 |
|---|---|---|
| 여행 목록 | 탭별 여행 조회, 여행 도구의 환율 확인, 새 여행 시작, 파일 가져오기, 설정 진입 | 앱 실행 |
| 새 여행 만들기 | 여행 기본 정보를 임시 계획으로 저장 | 여행 목록 → 새 여행 FAB |
| 여행 계획 작성·수정 | 날짜별 일정 작성과 이동, 후보 장소와 숙소 관리, 임시저장과 계획 완료 | 새 여행 만들기 → 일정 작성하기 / 작성 중 탭 → 여행 선택 / 여행 보기 → 계획 수정 |
| 여행 보기 | 일정·숙소 조회와 활성 여행의 준비물·예산·지출 관리 | 내 여행·지난 여행 탭 → 여행 선택 / 여행 계획 작성 → 계획 완료 |
| 일정 추가·수정 | 일정 생성, 편집, 삭제 | 예정·진행 여행 보기 → 일정 추가 / 여행 계획 작성·수정 → 일정 추가 또는 일정 카드 / 일정 지도 → 일정 보기 |
| 일정 지도 | 전체·일차별 일정 위치와 순서 확인 | 여행 보기 → 일정 지도에서 보기 / 여행 계획 작성·수정 → 지도 |
| 여행 수정 | 여행 정보와 기간 수정, 여행 삭제 | 여행 계획 작성·수정 → 기본 정보 수정 |
| 준비물 | 공통·개인 준비물 생성, 수정, 삭제와 체크 | 여행 보기 → 준비물 |
| 설정 | 현재 저장 방식 안내와 향후 설정 진입점 | 여행 목록 → 설정 |
| 여행 파일 공유 | 여행을 JSON 파일로 저장하거나 다른 앱에 공유 | 여행 보기 → 파일 공유 |
| 여행 파일 가져오기 | 공유 파일 검증, 미리보기, 새 여행 저장 | 여행 목록 → 여행 파일 가져오기 또는 외부 파일 열기 |

## 3. 기본 사용자 흐름

### 3.1 직접 여행 만들기

1. 홈 우측 하단의 새 여행 FAB를 선택한다.
2. 여행 기본 정보를 저장하면 정식 Viewer가 아닌 별도의 여행 계획 작성 화면으로 이동한다.
3. 계획 작성 화면에서 날짜별 일정을 작성하고 상단 `임시저장`으로 홈에 돌아간다.
4. 임시 저장한 계획은 `작성 중` 탭에서 다시 열어 같은 계획 작성 화면에서 수정한다.
5. `계획 완료`를 선택하면 `여행 보기` 화면을 연다. 홈에서는 예정·진행 여행을 `내 여행`에, 기간이 지났거나 완료 처리된 여행을 `지난 여행`에 표시한다.

계획 작성·수정 화면과 Viewer는 같은 여행·일정 데이터를 사용하지만 별도의 Screen과 ViewModel로 구분한다. 여행 보기에서 `계획 수정`을 선택하면 작성 화면으로 이동한다.

### 3.2 친구에게 여행 전달하기

1. 여행 보기에서 `파일 공유`를 선택한다.
2. `친구에게 공유` 또는 `기기에 파일 저장`을 선택한다.
3. 친구는 전달받은 `.tripplan.json` 파일을 앱으로 연다.
4. 파일 미리보기 내용을 확인하고 `새 여행으로 가져오기`를 선택한다.
5. 가져온 여행 보기 화면에서 원본과 같은 날짜 및 일정 구조를 확인한다.

파일은 특정 시점의 계획 사본이다. 가져온 뒤 각 사용자가 수정한 내용은 서로 자동 동기화되지 않는다.

## 4. 여행 목록 화면

### 표시 정보

- 여행을 `내 여행`, `작성 중`, `지난 여행` 탭으로 구분하고 각 탭에서 최근 수정 순으로 표시한다.
- 계획 작성을 완료한 예정·진행 여행은 `내 여행`, 임시 저장한 계획은 `작성 중`, 날짜가 지났거나 사용자가 완료 처리한 여행은 `지난 여행`에 표시한다.
- 여행 카드에는 여행 이름, 시작일·종료일, 목적지와 날짜 상태를 표시한다.
- 날짜 상태는 오늘을 기준으로 D-Day, 여행 중 일차 또는 여행 종료로 계산한다.
- 사용자가 완료한 여행은 날짜 상태와 별도로 완료 상태를 표시한다.
- 각 탭이 비어 있으면 해당 상태에 맞는 안내 문구만 표시하고 새 여행 버튼을 중복 노출하지 않는다.
- 상단 `여행 도구`를 열면 `오늘의 환율` 카드가 나타난다. 카드에는 선택한 통화의 원화 매매 기준율과 실제 환율 기준일을 표시한다.
- 최초 기본 통화는 미국 달러, 일본 엔, 유로이며 베트남 동을 포함한 지원 통화 중 표시 대상을 바꿀 수 있다.
- 환율은 `1 USD`, `100 JPY`, `1,000 VND`처럼 통화별 읽기 좋은 단위로 표시한다.
- 표시 금액은 반올림해 소수점 첫째 자리까지 보여준다.

### 사용자 동작

- 우측 하단 새 여행 FAB를 누르면 새 여행 만들기 화면이 열린다.
- `여행 파일 가져오기`: Android 문서 선택기를 열어 JSON 여행 파일을 선택한다.
- `통화 선택`: 조회된 통화 목록에서 홈에 표시할 통화를 하나 이상 선택한다.
- `새로고침`: 최신 환율을 다시 요청한다.
- `작성 중` 카드에서 계획 작성 화면을 열고, `내 여행`과 `지난 여행` 카드에서 여행 보기 화면을 연다. 종료일이 지난 임시 계획도 계획 완료 전까지 `작성 중`에 표시한다.

### 상태 및 오류

- 데이터를 읽는 동안 로딩 표시를 보여준다.
- Room 데이터 조회에 실패하면 앱을 다시 실행하도록 안내한다.
- 목록은 Room의 변경을 관찰하므로 여행 생성·수정·삭제 결과가 자동 반영된다.
- 앱 실행 시 Room에 마지막으로 저장한 정상 환율을 먼저 보여주고 최신 환율을 백그라운드에서 요청한다.
- 주말·휴일의 빈 응답은 최대 7일 전까지 직전 기준일을 조회하며, 네트워크 실패 시 기존 캐시를 유지한다.
- 선택 통화는 DataStore에 저장되어 다음 앱 실행에도 유지된다.
- 환율 조회에 실패하면 안내 문구를 표시하며 여행 목록 사용은 막지 않는다.

## 5. 새 여행 만들기 화면

### 입력 항목

| 항목 | 필수 여부 | 규칙 |
|---|---|---|
| 여행 이름 | 필수 | 공백만 입력할 수 없음 |
| 여행 국가 | 필수 | 기본값은 대한민국이며 선택한 국가의 대표 통화를 자동 적용 |
| 여행 도시 | 선택 | 두 글자 이상 입력하면 선택한 국가의 Google Places 도시 추천을 조회 |
| 여행 날짜 | 필수 | 시작일과 종료일을 범위로 선택하며 종료일은 시작일보다 빠를 수 없음 |
| 여행 메모 | 선택 | 여행 설명이나 준비 메모 입력 |

도시 추천은 네트워크와 Google Places 연동이 필요하다. 목적지 직접 입력과 저장은 오프라인에서도 가능하다.

### 사용자 동작

- 날짜 영역 선택: 날짜 범위 선택창을 연다.
- 오프라인 국가 목록에서 국가를 선택하면 대표 통화를 자동 변경하고 입력한 도시를 지운다.
- `일정 작성하기`를 누르면 입력값을 검증한 뒤 Room에 임시 계획을 저장한다.
- 입력 중 뒤로가면 작성 내용을 버릴지 확인한다.

### 상태 및 오류

- 여행 이름이나 날짜가 잘못되면 해당 입력란에 오류를 표시한다.
- 저장 중에는 중복 저장을 막고 진행 상태를 표시한다.
- 저장 실패 시 다시 시도할 수 있는 오류 메시지를 표시한다.
- 저장 성공 시 여행 계획 작성 화면을 연다.

## 5.1 여행 계획 작성·수정 화면

- 여행 기본 정보와 선택한 일차의 일정 목록을 표시한다.
- `기본 정보 수정`으로 여행 정보와 기간을 수정한다. `일정 추가` 또는 일정 카드 선택으로 일정 편집 화면을 열고, `지도`로 일정 지도를 연다.
- 일정 카드의 `일차 이동`에서 다른 일차를 선택하면 일정을 옮긴 뒤 해당 일차를 표시한다. 시간, 장소, 메모는 유지하며 지출은 기록한 날짜에 계속 표시한다.
- 기본 정보 아래 `숙소`에서 숙소 이름, 체크인·체크아웃 날짜와 숙박 일수를 확인한다. 숙소는 일정과 별도로 등록·수정·삭제한다.
- 숙소 이름과 체크인·체크아웃 날짜를 입력해 저장한다. 이름을 직접 입력하거나 저장한 장소와 Google Places 검색 결과에서 선택할 수 있으며 주소, 체크인·체크아웃 시각과 메모는 선택 사항이다. 다음 숙소의 체크인 날짜는 가능한 경우 이전 숙소의 체크아웃 날짜를 제안한다.
- 숙소는 여행 기간 안에서 하루 이상 등록한다. 앞 숙소의 체크아웃 날짜와 다음 숙소의 체크인 날짜는 같을 수 있다. 일차 탭 아래에는 체크인, 숙박, 체크아웃 또는 숙소 이동을 표시한다. 안내를 누르면 주소·체크인 및 체크아웃 시각·메모를 펼쳐 볼 수 있다. 숙소 목록의 `지도`는 외부 Google Maps 앱이나 웹을 열며, 직접 입력한 숙소는 이름과 주소로 검색한다.
- 기본 정보 아래 `후보 장소`에서 방문 날짜를 정하기 전 장소를 모은다. 이름 직접 입력, 저장한 장소 선택, Google Places 검색을 지원하고 주소와 메모는 선택 항목이다.
- 후보의 `일정에 넣기`에서 현재 일차나 다른 일차를 고른다. 장소 이름·장소·메모가 시간 미정 일정으로 추가되고, 후보에는 연결된 일차가 표시된다. 후보 삭제 후에도 연결된 일정은 유지된다.
- 후보 목록은 해당 여행과 함께 기기에만 저장된다. 일정으로 추가한 항목은 기존 일정과 같은 공유 규칙을 따른다.
- 임시 계획에서 `임시저장`을 누르면 홈으로 돌아가고, `계획 완료`를 누르면 작성 상태를 완료로 바꾼 뒤 여행 보기 화면을 연다. 일정 변경은 각 일정의 저장 동작에서 반영한다.
- 기존 계획을 수정한 뒤 `수정 완료`를 누르면 여행 보기로 돌아간다.
- 불러오기 또는 계획 상태 저장에 실패하면 화면에 안내를 표시한다.

## 6. 여행 보기 화면

종료일이 지났거나 사용자가 완료 처리한 여행은 읽기 전용이다. 여행 정보, 날짜별 일정, 저장된 예산·지출, 결산과 일정 지도를 열람할 수 있다. 파일 공유, 계획 수정, 준비물, 완료 상태 변경, 예산·지출 편집과 지도에서의 일정 수정은 진행 전이나 진행 중인 여행에서 사용할 수 있다.

### 표시 정보

- 여행 이름, 목적지, 여행 기간과 메모를 표시한다. 전체 숙소 목록은 타임라인 아래에서, 당일 체크인·체크아웃 및 숙소 이동은 일차 탭 바로 아래에서 조회할 수 있다.
- 여행 기간을 `1일차`, `2일차`와 같은 일차 탭으로 표시한다. 진행 중인 여행을 열면 기기 날짜 기준 오늘 일차를 먼저 선택한다.
- 선택한 날짜에 속한 일정만 카드 목록으로 표시한다.
- 일차 탭과 당일 숙소 안내 아래에 일정 타임라인을 둔다. 왼쪽에 시간, 오른쪽 카드에 제목·장소·메모와 사진·연결 지출을 표시한다. 전체 숙소 목록과 여행 예산은 타임라인 아래에서 확인한다.
- 타임라인 아래의 여행 예산에 총예산, 예상 지출, 실제 사용 합계와 남은 예산을 표시한다.
- 선택한 일차 상단에는 해당 날짜 일정의 실제 사용 금액 합계를 표시한다.
- 저장된 예상 비용을 일정 카드에 표시한다. 실제 사용금액은 일정 카드의 `지출 추가`로 기록한다.
- 선택한 날짜에 일정이 없으면 빈 일정 메시지를 표시한다.
- 진행 중인 여행의 일정에서 `사진 추가`로 사진을 직접 찍거나 사진첩에서 선택한다. 일정 카드에는 썸네일을 최대 3장 표시하며 나머지는 `+N`으로 안내한다. 썸네일이나 `+N`을 누르면 전체 화면에서 좌우로 넘겨 볼 수 있다. 지난 여행에도 같은 방식으로 표시한다.
- 직접 촬영을 선택했을 때 카메라 권한 이유를 안내한다. Android Photo Picker를 통한 사진첩 선택에는 저장소 권한이 필요 없다. 사진은 기기에 저장되며 여행 파일에 포함되지 않는다.
- 일정 시간대에 기록한 지출은 해당 일정 카드 안에 시간·카테고리·금액으로 표시한다.
- 일정 시간대 밖에 기록한 지출은 해당 시각 위치에 `추가 지출` 아이템으로 표시한다.
- 합계는 대표 통화와 원화 전환 중 선택한 하나의 통화로 통일해 표시한다. 최초 기본값은 예정 여행은 원화, 진행 중 여행은 대표 통화이며 여행별 선택을 기억한다.
- 개별 지출은 영수증 확인이 쉽도록 실제 입력 통화를 크게, 반대 통화 환산액을 작게 표시한다.
- `지출 현황 보기`를 선택하면 화면을 가득 채우는 지출 요약 팝업을 연다.
- 지출 요약 팝업은 실제 기록이 있는 카테고리만 원형 차트와 비율로 표시하고, 금액이 큰 카테고리부터 금액 목록과 총액을 표시한다.
- 진행 중인 여행은 `누적 지출 현황`, 지난 여행은 `여행 지출 결산`으로 표시하며 대표 통화·원화 보기 선택을 함께 따른다.
- 일정 안 지출과 독립 `추가 지출`을 누르면 전체 화면형 편집 팝업에서 금액, 입력 통화, 카테고리와 시간을 수정하거나 지출을 삭제할 수 있다.

### 사용자 동작

- 일차 탭 선택: 해당 날짜의 일정 목록으로 전환한다.
- 예정·진행 여행에서 `지출 추가` 옆의 `일정 추가`를 누르면 선택한 일차로 일정 입력 화면을 연다. 저장 후 여행 보기로 돌아온다.
- `계획 수정`을 누르면 여행 계획 작성·수정 화면으로 이동한다.
- `파일 공유`: 여행 파일 공유 화면으로 이동한다.
- `준비물`: 공통·개인 준비물 화면으로 이동한다.
- `일정 지도에서 보기`: 전체 또는 일차별 일정 위치와 순서를 지도에서 확인한다.
- `여행 완료`를 누르고 확인하면 로컬 완료 상태가 저장되고 화면이 읽기 전용으로 바뀐다.
- `예산 설정`·`추가 예산`: 원화 금액을 입력하면 저장된 최신 정상 환율로 여행 대표 통화 금액을 즉시 보여주고, 저장 시 원화 입력액과 대표 통화 환산액·적용 환율·기준일을 고정한다.
- 예산 환율은 사용자가 직접 입력하지 않으며 여행 국가에 연결된 대표 통화를 자동 사용한다.
- 일정 카드의 `지출 추가`: 선택한 일정에 직접 연결되는 실제 지출을 추가한다.
- `지출 추가`: 현재 시각과 여행 대표 통화를 기본으로 금액과 카테고리를 입력한다. 현재 시각이 일정의 시작 이상·종료 미만이면 일정에 연결하고, 아니면 시간순 독립 지출로 추가한다.
- 지출 입력 중 대표 통화와 KRW를 전환할 수 있고 입력과 동시에 반대 통화 환산값을 표시한다.
- 지출 추가·수정에서 `기타`를 선택하면 설명을 입력할 수 있다. 저장한 설명은 일정 연결 지출과 독립 지출 내역에 표시된다.
- 지출 수정은 기록 당시 환율과 기준일을 유지하며, 시간을 변경하면 같은 날짜의 일정 시간대와 다시 비교해 일정 연결 또는 독립 지출 위치를 갱신한다.
- 지출 삭제는 확인 팝업을 거친 뒤 실행하며 여행·일차 합계와 카테고리 요약을 즉시 갱신한다.
- 예산·지출 금액 입력칸은 `3,800`, `1,000,000`처럼 천 단위 쉼표를 자동 적용하며 소수점 입력도 유지한다.
- `대표 통화`·`원화`: 총예산, 예상 지출, 실제 사용, 남은 예산, 지출 요약과 일차 사용금액의 표시 통화를 한 번에 변경한다.

일정은 시작 시간이 빠른 순서로 표시하며 시작 시간이 없는 일정은 뒤에 표시한다.

전체 지출 목록 전용 화면과 날짜·카테고리 필터는 현재 제공하지 않는다.

### 상태 및 오류

- 여행 또는 일정 조회 중에는 로딩 상태를 표시한다.
- 삭제되었거나 존재하지 않는 여행이면 찾을 수 없다는 메시지를 표시한다.

## 7. 일정 추가·수정 화면

일정 추가와 수정은 같은 화면을 사용한다. 기존 일정 ID가 있으면 수정 모드, 없으면 추가 모드로 동작한다.

### 입력 항목

| 항목 | 필수 여부 | 규칙 |
|---|---|---|
| 일차·날짜 | 필수 | 여행 기간 안의 날짜만 선택 가능 |
| 일정 제목 | 필수 | 공백만 입력할 수 없음 |
| 장소 | 선택 | 직접 입력, 저장된 장소 선택 또는 Google Places 검색 |
| 시작 시간 | 선택 | 24시간제 시간 선택기로 입력하고 `HH:mm` 형식으로 저장 |
| 종료 시간 | 선택 | 24시간제 시간 선택기로 입력하고 `HH:mm` 형식으로 저장하며 시작 시간보다 빠를 수 없음 |
| 메모 | 선택 | 일정 관련 메모 |

### 사용자 동작

- 일차 선택: 일정을 다른 여행 날짜로 이동하거나 새 일정 날짜를 지정한다.
- 시간 선택: 시간 선택창의 시·분 목록을 세로로 스크롤한 뒤 각 값을 눌러 고른다. 선택한 시작·종료 시간은 개별적으로 지울 수 있다.
- 장소를 두 글자 이상 입력하면 Google Places 추천을 조회한다. 추천 장소를 선택하면 장소 상세를 불러와 저장한다.
- `일정 추가` 또는 `일정 저장`을 누르면 입력값을 검증해 저장하고 이전 화면으로 돌아간다.
- 새 일정에서 `다음 일정`을 누르면 현재 일정을 저장하고 같은 일차의 새 일정 입력을 이어간다.
- `일정 삭제`: 수정 모드에서만 표시되며 확인창을 거쳐 삭제한다.
- 뒤로가면 현재 입력을 저장하지 않고 이전 화면으로 돌아간다.

### 저장 후 정렬

- 시작 시간이 빠른 일정부터 자동 정렬한다.
- 시작 시간이 없는 일정은 뒤로 이동한다.
- 동일한 시간의 일정은 기존 사용자 순서를 최대한 유지한다.
- 삭제 후 남은 일정의 순서는 0부터 다시 정규화한다.

### 상태 및 오류

- 제목 누락, 시간 형식 오류와 종료 시간이 더 빠른 경우를 표시한다.
- 여행 기간 밖의 날짜는 저장하지 않는다.
- 저장·삭제 실패 시 현재 입력을 유지하고 오류 메시지를 표시한다.
- 일정 삭제 성공 시 이전 화면으로 돌아간다.

## 7.1 일정 지도 화면

일정 지도는 여행 전체 일정을 하나의 Google 지도에서 확인하는 선택적 온라인 화면이다. 지도 로드가 실패해도 여행과 일정의 생성·조회·수정은 계속 사용할 수 있다.

### 표시 및 동작

- `전체`, `1일차`, `2일차` 필터로 표시할 일정 범위를 바꾼다.
- 전체 보기의 마커는 `1-1`, `1-2`, `2-1`처럼 일차와 일차 내 순서를 함께 표시한다.
- 일차 보기의 마커는 `1`, `2`, `3`처럼 해당 일차 순서만 표시한다.
- 같은 일차에서 좌표가 연속으로 저장된 일정을 순서대로 직선 연결하며 서로 다른 일차는 연결하지 않는다.
- 일정 카드나 마커를 선택하면 해당 위치로 확대하고, 지도 빈 영역을 누르거나 선택을 해제하면 현재 필터의 모든 마커가 보이도록 카메라 범위를 맞춘다.
- 작성 중이거나 진행 전·진행 중인 여행의 하단 일정 시트에서는 `일정 보기`로 일정 수정 화면을 열 수 있다. 좌표가 저장된 일정은 `Google 지도`로 외부 지도를 열 수 있다.
- 좌표가 없는 일정은 `위치 미지정`으로 목록에 남기며 연결선은 그 일정에서 끊는다.
- 일정과 구조화 장소의 연결은 로컬 `placeId`로 유지한다. 과거 연결 누락 데이터는 장소명이 정확히 일치하는 저장 장소가 하나일 때만 지도 표시에서 좌표를 복구한다.

### 현재 제외 범위

- 계획선의 실제 도로 경로 변환과 길찾기
- 현재 위치 표시와 주변 장소 검색
- 백그라운드 또는 실시간 위치 추적
- 실제 이동 좌표 기록과 이동 경로 선 표시

## 8. 여행 수정 화면

### 수정 가능한 항목

- 여행 이름
- 여행 국가와 자동 결정된 대표 통화
- 여행 지역
- 시작일과 종료일
- 여행 메모

입력 규칙은 새 여행 만들기와 동일하다.

예산이나 지출이 있는 여행의 국가를 변경하면 기존 예산, 일정 예상 비용과 지출이 새 통화와 섞이지 않도록 초기화 확인창을 표시한다. 확인한 경우에만 국가 변경과 금액 초기화를 하나의 Room 트랜잭션으로 처리한다.

### 기간 변경 보호

- 여행 기간을 줄여 기존 일정이 새 기간 밖으로 나가면 즉시 삭제하지 않는다.
- 삭제 대상 일정 개수를 확인창에 표시한다.
- 사용자가 `삭제 후 변경`을 선택한 경우에만 여행 기간 변경과 범위 밖 일정 삭제를 하나의 트랜잭션으로 처리한다.
- 취소하면 기존 여행과 일정을 유지한다.

### 여행 삭제

- `여행 삭제`를 선택하면 복구할 수 없다는 확인창을 표시한다.
- 확인하면 여행과 모든 연관 일정을 함께 삭제한다.
- 삭제 성공 시 내비게이션 기록을 정리하고 여행 목록으로 이동한다.

### 상태 및 오류

- 여행을 찾을 수 없는 상태와 조회 실패 상태를 구분한다.
- 저장·삭제 중에는 중복 동작을 막는다.
- 처리 실패 시 다시 시도할 수 있도록 현재 화면을 유지한다.

## 9. 여행 파일 공유 화면

### 표시 정보

- 생성될 `.tripplan.json` 파일 이름을 표시한다.
- 공유 파일에 여행·일정·공통 준비물·구조화 장소 사본만 포함되고 계정이나 기기 정보는 포함되지 않는다고 안내한다.

### 사용자 동작

- `친구에게 공유`: 앱 캐시에 공유 파일을 만들고 Android 공유 시트를 연다.
- `기기에 파일 저장`: Android 문서 생성 화면을 열어 사용자가 선택한 위치에 저장한다.

### 파일 내용

- 파일 포맷 버전
- 여행 이름, 목적지, 기간과 메모
- 일정 날짜, 제목, 장소, 시간, 메모와 순서
- 공통 준비물의 이름, 카테고리, 수량, 메모와 순서
- 구조화 장소의 이름, 주소와 선택적 좌표

후보 장소 목록, 숙소 목록, Room ID, 개인 준비물, 체크·완료 상태, 캐시 경로, 기기 경로, 생성 시각과 UI 상태는 파일에 포함하지 않는다.

### 상태 및 오류

- 파일 생성·저장 중에는 버튼을 비활성화하고 진행 상태를 표시한다.
- 저장 성공 메시지와 파일 생성·쓰기 실패 메시지를 구분해 표시한다.
- 새 내보내기는 [공유 파일 형식 v2](FILE_FORMAT_V2_DRAFT.md)를 따르며 기존 v1 파일 가져오기도 지원한다.

## 10. 여행 파일 가져오기 화면

### 진입 방법

- 여행 목록의 `여행 파일 가져오기`에서 파일을 선택한다.
- 파일 앱이나 메신저에서 JSON 파일을 Trip Plan 앱으로 연다.

### 저장 전 검증

- JSON 문법과 공유 파일 구조
- `formatVersion` 지원 여부
- 여행 제목과 날짜 범위
- 각 일정 날짜가 여행 기간 안에 있는지 여부
- 일정 제목, 시간 형식과 순서 값

검증을 통과하기 전에는 Room 데이터를 변경하지 않는다.

### 미리보기 정보

- 여행 이름과 목적지
- 시작일과 종료일
- 전체 여행 일수
- 일정 개수

### 사용자 동작

- `새 여행으로 가져오기`: 기존 여행을 수정하지 않고 새 로컬 ID를 가진 여행과 일정을 저장한다.
- 뒤로가기: 아무 데이터도 저장하지 않고 이전 화면으로 돌아간다.

가져오기 성공 시 새로 생성된 여행의 상세 화면으로 이동한다. 같은 파일을 다시 가져오면 기존 여행을 덮어쓰지 않고 별도의 여행으로 추가한다.

### 오류 안내

| 오류 | 사용자 안내 |
|---|---|
| 파일 읽기 실패 | 파일을 읽지 못했습니다. |
| JSON 또는 구조 오류 | 여행 계획 파일 형식이 아닙니다. |
| 미지원 버전 | 현재 앱에서 지원하지 않는 파일 버전입니다. |
| 날짜·일정 데이터 오류 | 파일의 여행 또는 일정 정보가 올바르지 않습니다. |

가져오기 저장은 하나의 Room 트랜잭션으로 처리한다. 일정 하나라도 저장에 실패하면 새 여행과 앞서 저장된 일정까지 모두 롤백하며 기존 로컬 여행은 변경하지 않는다.

## 11. 2단계 추가 화면

### 준비물

- 공통 준비물과 내 준비물을 구분해 표시한다.
- 항목을 추가·수정·삭제·체크할 수 있으며 생성 후 유형은 변경할 수 없다.
- 공통 준비물만 공유 파일에 포함하고 개인 준비물과 체크 상태는 기기에만 남긴다.

### 설정

- 여행 데이터가 기기에 저장되고 파일로 공유된다는 안내를 표시한다.
- 실제 설정값이 없으므로 DataStore나 동작하지 않는 설정 스위치는 제공하지 않는다.

## 12. 화면 이동 규칙

- 일반적인 뒤로가기는 직전 화면으로 돌아간다.
- 새 여행 기본 정보 저장 후 계획 작성 화면을 열고, 계획 완료 후 여행 보기 화면을 연다.
- 여행 기본 정보 수정과 일정 저장·삭제가 끝나면 이전 화면으로 돌아간다. `다음 일정`으로 저장하면 일정 입력을 이어간다.
- 여행 삭제 성공 시 여행 목록을 새로운 기준 화면으로 만든다.
- 파일 가져오기 성공 시 가져오기 화면을 제거하고 새 여행의 여행 보기 화면을 연다.
- 외부 파일로 앱을 실행해도 먼저 가져오기 미리보기를 보여주며 자동 저장하지 않는다.

## 13. 공통 기술 및 검증 기준

- 모든 화면은 ViewModel의 단일 `StateFlow` UI 상태를 관찰한다.
- 화면은 Repository, DAO와 파일 시스템을 직접 호출하지 않고 UseCase를 통해 동작한다.
- 저장 성공, 삭제 성공과 공유 실행 같은 일회성 동작은 UI 상태와 별도 이벤트로 처리한다.
- 각 Compose 화면에는 기본·데이터·오류 상태를 확인할 Preview가 있다.
- 화면과 ViewModel 동작은 Unit Test 및 실제 기기 Compose 계측 테스트로 검증한다.
- 핵심 여행 기능은 네트워크, 계정, 로그인과 서버 없이 동작한다.

## 14. 현재 화면 범위에서 제외된 기능

사진 돌아보기, 사진 코멘트와 실제 이동 경로 등 논의한 항목은 [남은 기능과 검증](../planning/DEVELOPMENT_PLAN.md#남은-기능과-검증)에 기록한다.

여행 보기에는 여행 복사와 저장된 장소 관리 진입점이 없다. 일정 추가·수정에서 저장된 장소를 계속 선택할 수 있다.

현재 작성·조회 화면에는 일정 수동 순서 변경과 예상 비용 편집 진입점이 없다. 저장된 예상 비용은 여행 보기에서 확인할 수 있다.

- 로그인과 계정 화면
- 서버 동기화 및 실시간 공동 편집
- 지도 핀 지정, 현재 위치·주변 장소 검색, 실제 도로 경로와 실시간 이동 추적
- 채팅과 친구 목록
- 여행 일지와 여행 전체 사진 갤러리
- 서로 다른 여행 파일의 자동 병합 또는 덮어쓰기
- 외부 지도 앱의 공유 메뉴에서 후보 장소나 일정으로 가져오기

이 기능들은 현재 화면 범위에 포함하지 않으며 후속 요구사항 확정 후 별도로 설계한다.
