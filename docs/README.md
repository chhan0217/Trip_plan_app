# Trip Plan 문서 안내

프로젝트의 제품, 계획, 규칙 관련 문서는 이 폴더에서 관리한다.

## 폴더 구성

- `product`: 제품 방향과 기능 명세
- `planning`: 개발 순서와 진행 상태
- `rules`: 개발 및 문서 관리 규칙 안내

## 주요 문서

- [제품 기능 및 단계별 개발 명세](product/FEATURES.md)
- [화면별 기능 안내](product/SCREEN_FEATURES.md)
- [공유 파일 형식 v1](product/FILE_FORMAT_V1.md)
- [공유 파일 형식 v2 계약](product/FILE_FORMAT_V2_DRAFT.md)
- [2단계 요구사항 확정 기록](product/STAGE2_REQUIREMENTS.md)
- [단계별 개발 계획](planning/DEVELOPMENT_PLAN.md)
- [2단계 14일 개발 계획](planning/STAGE2_DEVELOPMENT_PLAN.md)
- [환율 API 네트워크 기반](planning/NETWORK_FOUNDATION.md)
- [개발 규칙 안내](rules/README.md)

개발 중 사용하는 공식 기준 문서는 Markdown(`.md`) 형식으로 관리한다. 사용자가 제공한 DOCX와 교체된 문서는 참고용 원본으로 `archive` 폴더에 보존하며, 개발 기준으로 직접 사용하지 않는다.

새 문서를 추가할 때는 문서의 목적에 맞는 하위 폴더에 저장하고 이 문서의 목록도 함께 갱신한다.
